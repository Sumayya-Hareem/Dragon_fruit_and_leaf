# Background photo

Save a photo here as `background.jpg` (`.jpeg`, `.png` and `.webp` also work) and the app uses it as the page
background, with a dark overlay so the text stays readable. Any size is fine; the app shrinks it to 1920 px wide.
Without a photo the app falls back to a dragon-fruit coloured gradient.

Use a photo you took yourself or one whose licence allows free use, and keep the licence note with it.
